# Phase 3 — Calibrated edge, before vs after (fix/edge-calibration, 2026-08-06)

Generated by `scripts/calibrate_and_recompute_edge.py` (report-only). Fit sample: 283
resolved predictions for the deployed `model_version=b9133b95d2ec`. Evaluation sample:
the same 222 rated+resolved bets used in Phase 2 (2026-07-16 → 08-06). Calibrated
probabilities are **out-of-fold** (5-fold CV), so no bet is scored by a calibrator that
saw its own outcome.

## Headline

**Calibration does NOT resolve the inversion — it makes it nominally worse. Do not ship
it into the live edge path.**

| | Value Bets | Toss-Ups | gap | p |
|---|---|---|---|---|
| A — as-labeled (what the page shows) | 42-35, **54.5%** | 63-43, 59.4% | −4.9pp | 0.509 |
| B — production edge, thresholds applied consistently | 39-28, **58.2%** | 63-43, 59.4% | −1.2pp | 0.873 |
| C — **calibrated edge**, same thresholds | 26-23, **53.1%** | 77-46, 62.6% | **−9.5pp** | 0.249 |

The Phase 4 gate ("if calibrated edge resolves the inversion, ship it") is **not met.**

## 3a. Fitted Platt scaling — calibration itself improves a lot

```
calibrated_logit = +0.0132 + 0.7719 * logit(raw_prob)

ECE  production flat blend : 0.0242
ECE  Platt (out-of-fold)   : 0.0097     <- 2.5x better calibrated
Brier production           : 0.2426
Brier Platt (out-of-fold)  : 0.2452     <- very slightly worse
prob range production      : [0.292, 0.778]
prob range calibrated      : [0.365, 0.754]
```

The **slope of 0.772 (< 1) is direct confirmation that the model is overconfident** — the
honest fit shrinks the spread of every probability toward 0.5 by ~23%, and the fitted
intercept is ~0, so there is no systematic home/away shift to correct, only excess
confidence. This independently validates the Phase 1 mechanism.

Note the live ECE here (0.0242) is already better than the ~0.05 recorded in CLAUDE.md
(n=91, 07-22) and much better than the pre-leak-fix 0.08 — the current model is
substantially better calibrated than the docs claim, on a bigger sample.

**But better calibration does not mean better betting.** Brier score actually gets
marginally *worse* (0.2426 → 0.2452), which is the tell: Platt is fixing the confidence
*scale* while adding nothing to the model's ability to *discriminate* winners from losers.

## 3b. What recalibration does to edge — it shrinks it

```
mean |edge|  production 0.0678 -> calibrated 0.0601
max  edge    production 0.5472 -> calibrated 0.5322
bets with edge > 0.12:      27 -> 22
bets with edge > 0.05:      94 -> 71
```

Shrinking probabilities toward 0.5 shrinks edge, so ~25% of value bets stop qualifying.
That is the intended effect — but the bets it removes are not disproportionately losers,
which is why the win rate does not improve.

## 3e. The decisive caveat — none of this is statistically significant

| scenario | Value | 95% CI | Toss-Up | 95% CI | gap | p |
|---|---|---|---|---|---|---|
| A as-labeled | 42/77 = 54.5% | [43.5, 65.2] | 63/106 = 59.4% | [49.9, 68.3] | −4.9pp | 0.509 |
| B consistent | 39/67 = 58.2% | [46.3, 69.3] | 63/106 = 59.4% | [49.9, 68.3] | −1.2pp | 0.873 |
| C calibrated | 26/49 = 53.1% | [39.4, 66.3] | 77/123 = 62.6% | [53.8, 70.6] | −9.5pp | 0.249 |

```
Does edge predict the pick winning?  logit(win) ~ const + model_edge
  edge coef = -1.3419  se=1.6645  p=0.420

Does the model add information beyond the market?  logit(home win) ~ const + market + model
  market  coef=+0.8130  se=0.4616  p=0.078
  model   coef=+0.7996  se=0.4284  p=0.062
```

Three things follow, and they matter more than any table above:

1. **The inversion itself is not statistically distinguishable from noise** (p = 0.51 in
   the as-labeled form the investigation started from). The confidence intervals overlap
   heavily in all three scenarios. The original premise — "toss-ups beat value bets" — is
   a real pattern in the sample but is not established as a real property of the model.
2. **Edge has no demonstrable relationship with winning** (p = 0.42). The point estimate
   is slightly negative, consistent with Phase 2's non-monotonic buckets, but at n=222 we
   cannot reject "edge is uninformative." Both the bullish and bearish readings of edge
   are currently unsupported.
3. **Whether the model beats the market is still an open question.** Model and market
   carry near-identical weight (+0.80 vs +0.81) and are individually marginal (p ≈ 0.06 /
   0.08) because they are highly collinear. Model AUC 0.598 vs market AUC 0.594 is a tie.
   The model is not clearly adding skill over the closing market — which is the real
   reason edge does not convert into profit, and is a *feature/signal* problem that no
   probability transform can fix.

## Verdict

- **Root cause of the inversion: NOT confirmed as miscalibration.** The Phase 1 mechanism
  is real (edge is built on an overconfident probability; Platt's 0.77 slope proves the
  overconfidence). But correcting it does not fix the outcome, so miscalibration is not
  what is driving the observed pattern.
- **Do NOT ship the calibrator into the live edge path.** It fails the Phase 4 gate on its
  own terms, cuts value-bet volume by a third, drops flat-bet ROI from +10.3% to +0.8%,
  and none of its effects are significant.
- **The one change actually supported by this analysis is the cheap one**: `bet_rating` is
  frozen at odds-attach time, so the page's buckets mix two rating vintages. Re-rating on
  read (or backfilling the 10 stale rows) is a pure bookkeeping fix, requires no model
  change, and by itself accounts for +$14 of the missing Quarter-Kelly P/L.
- **The deeper open question is discrimination, not calibration**: at n=222 the model does
  not demonstrably beat the market. That is where further investigation belongs — feature
  quality and whether the model has any real edge over closing lines — not in the
  probability-transform layer.
- **Sample is the binding constraint.** 222 rated bets is well under the ~200+ *value-bet*
  decision-grade bar used elsewhere in this repo (`scripts/backtest_threshold.py:31`), and
  the 3-day odds blackout cost ~41 more. Re-run this script once the sample roughly
  doubles before drawing firmer conclusions.
